# CampusFix – Campus Issue Reporting and Tracking Platform

## About the Project

CampusFix is a web-based platform designed to make reporting and tracking campus-related issues easier. It provides a central place where students can report problems and help improve the overall campus environment.

## Features

- Simple and user-friendly interface.
- Campus issue reporting platform.
- Easy navigation through the website.
- Centralised platform for campus-related concerns.
- Responsive website design.

## Technologies Used

- HTML – Website structure.
- CSS – Styling and layout.
- JavaScript – Interactive functionality.

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/navyasharma1236-abc/CampusFix.git`

2. Open the project folder in VS Code.

3. Open `index.html` in your browser to view the website.
